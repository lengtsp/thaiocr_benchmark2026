### หมายเหตุการทดสอบ

- **Pixel ที่ทดสอบ:** 1,024, 1,400, 1,600, 1,800, 2,000 และ 2,200 px วัดทั้ง `raw` และ `gray220` รวม 48 run.
- **raw** คือภาพ render ต้นฉบับ. **gray220** คือแปลงเป็น grayscale แล้วแทน pixel ที่มี luminance ตั้งแต่ 220 ด้วยสีขาว เพื่อลด watermark สีอ่อน; เป็น preprocessing ของภาพ ไม่ใช่ parameter หรือ fine-tune ของโมเดล.
- เงื่อนไขร่วม: หนึ่งภาพต่อ request, `temperature=0`, client concurrency=7, vLLM `max-num-seqs=7`, `max_tokens=8192`; **ไม่ใช้ PP-DocLayoutV3, crop หรือ rotate**.
- Qwen ใช้ MTP ปิด เพราะ vLLM บน SM120 ล้มเหลวขณะจัดสรร MTP CUDA buffer. OpenThai ใช้ MTP 3 ได้จริง; Pathumma และ Typhoon ไม่ได้ใช้ MTP.
- Qwen gray220 2,200 px ชนะ Word accuracy อยู่ 0.292 percentage point แต่ raw 2,200 px มีเลขไทย/ตัวเลขสูงกว่า (78.846% เทียบกับ 78.297%) และรวมความต่างต่ำกว่า (701 เทียบกับ 743). หากงานให้ความสำคัญกับตัวเลข ให้เลือก Qwen raw 2,200 px แทน.
- Typhoon 1,800 และ 2,200 px ได้ Word accuracy/รวมความต่างเท่ากัน; เลือก 1,800 px เพราะคะแนนตัวเลขสูงกว่าและเร็วกว่า.

### นิยามการเทียบกับ Golden

- **ถูกตรง**: token OCR ที่ align ตรงกับ Golden
- **แทนผิด**: token OCR ที่แทน token Golden คนละคำ
- **คำหาย**: token ใน Golden ที่ OCR ไม่มี
- **คำเกิน**: token ที่ OCR เพิ่มขึ้นโดยไม่มีคู่ใน Golden
- **รวมความต่าง** = แทนผิด + คำหาย + คำเกิน. Word accuracy ใช้ `ถูกตรง / (ถูกตรง + แทนผิด + คำหาย)` ดังนั้นคำเกินแยกรายงานเพื่อไม่ให้ ปิดบัง hallucination/repetition.
