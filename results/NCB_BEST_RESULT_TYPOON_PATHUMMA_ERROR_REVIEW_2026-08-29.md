# NCB Golden: รีวิวคำคลาดเคลื่อนของ Typhoon และ Pathumma

รีวิวนี้ใช้ผล Best Result บน Golden dataset พระราชบัญญัติการประกอบธุรกิจข้อมูลเครดิต
21 หน้า: Typhoon fixed prompt + `gray220` 1,800 px และ Pathumma `gray220` 1,600 px.
การ align เปรียบเทียบระดับ token โดย normalize whitespace/newline ก่อนแล้ว จึงไม่ได้
นับการขึ้นบรรทัดหรือเว้นวรรคต่างกันเป็นข้อผิดพลาด.

`แทนผิด` คือ token OCR แทน token Golden คนละค่า, `คำหาย` คือ token Golden ที่ไม่พบ
ใน OCR และ `คำเกิน` คือ token OCR ที่ไม่มีคู่ใน Golden. หลายค่าติดกันโดยเฉพาะเลข
เชิงอรรถอาจเป็นผลจากการแยก/รวม token; จึงให้ข้อสังเกตประกอบ ไม่สรุปว่าเป็น semantic
error โดยอัตโนมัติ.

## Typhoon OCR 1.5

สรุป: แทนผิด 4, คำหาย 1, คำเกิน 0, รวม 5 จุด. ใช้ fixed prompt, `gray220`,
1,800 px. ความต่าง 4 จุดเป็นเลขเชิงอรรถ/เลขอ้างอิงที่ถูกตัด; หน้า 12 มีคำ `ได้`
หายหนึ่งจุดซึ่งมีผลต่อวลี.

| หน้า | ประเภท | ผล OCR | Golden | รีวิว |
|---:|---|---|---|---|

| 12 | คำหาย | - | `ได้` | คำในวลีหาย; ต้องตรวจบริบทของประโยคเมื่อนำไปอ้างอิง |

| 19 | แทนผิด | `๒๕๕๑` | `๒๕๕๑๒๑` | ปีและเลขเชิงอรรถติดกันใน Golden; OCR ขาดเลขอ้างอิงท้าย |
